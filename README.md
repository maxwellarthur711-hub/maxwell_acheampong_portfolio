# Maxwell Acheampong — Portfolio Website

A responsive, single-page portfolio starter for Data Analytics and Data Science.

## Files
- `index.html` — page content and sections
- `style.css` — layout, typography, colours and responsive design
- `script.js` — mobile navigation and current year

## Before publishing — personalise these items
1. Replace the About section with your real education, background and professional interests.
2. Replace the three sample project cards with projects you have actually completed.
3. For every project, include the problem, dataset/source, method, tools, findings, limitations and a link to the code/notebook/report.
4. Replace `YOUR_EMAIL@example.com`, `YOUR-LINKEDIN` and `YOUR-GITHUB` in `index.html` with your real links.
5. Update the skills list so it only includes tools and techniques you can genuinely demonstrate.
6. Add real education, work experience and certificates; remove any section entries that do not apply.

## Preview locally
Open `index.html` in a browser. You can also use Visual Studio Code with the Live Server extension.

## Publish free with GitHub Pages
1. Create or sign in to a GitHub account.
2. Create a **public** repository named `YOUR-GITHUB-USERNAME.github.io`.
3. Upload `index.html`, `style.css` and `script.js` to the repository root.
4. Open repository **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select branch `main`, folder `/(root)`, then save.
7. Wait for the site to deploy. Visit `https://YOUR-GITHUB-USERNAME.github.io`.

GitHub Pages sites are public. Do not upload private datasets, personal records, passwords, API keys or confidential employer/client information.
